# GG TV 安装说明（Windows）

GG TV 的 GitHub 仓库名是 `ggtv-canvas`。普通用户下载发版里的 `ggtv-canvas-版本号-win.zip` 整合包；整合包已包含页面，不需要运行 `npm install`。深度和白模都是选装，不装也能使用其他功能。

## 先把整合包用起来

1. 从 [Node.js 官网](https://nodejs.org/) 安装 **Node 22 LTS，22.12.0 或以上的 22.x**。装完关掉原来的命令窗口。
2. 打开 Windows 终端，运行一次下面的命令安装 ffmpeg（同时带 ffprobe）。如果电脑没有 winget，可以自行安装包含这两个程序的 ffmpeg Windows 版本，并确认新窗口中都能找到它们。

   ```powershell
   winget install Gyan.FFmpeg
   ```

3. 把 zip 完整解压到自己选的文件夹，别在压缩包里直接双击。先用一个普通的、可写的目录，留出作品占用的硬盘空间。
4. 把文件夹里的 `.env.example` **复制**一份，改名为 `.env.local`，用记事本打开它。这里是文件，不是文件夹。资源管理器打开“显示文件扩展名”，避免误存成 `.env.local.txt`；另存为时选“所有文件”和 UTF-8。
5. 把 `ARK_API_KEY` 的提示文字换成自己的火山方舟密钥。参考视频上传需要填写 `TOS_ACCESS_KEY_ID`、`TOS_SECRET_ACCESS_KEY`、`TOS_BUCKET`，桶用北京区。`ARK_BASE_URL` 不知道怎么填就留空。等号两边别加空格，值不用加引号。没用到的选装配置可以先留着提示文字。密钥只放在自己电脑里，不要发给别人，也不要上传到 GitHub。
6. 双击 `一键启动.bat`。看到“整合包：页面已打包好”是正常的。浏览器会打开 `http://127.0.0.1:5290`；没打开就自己复制这个地址。只在这台电脑上访问。
7. 用完关掉启动的黑窗口，或双击 `停止.bat`。停止脚本只处理 5290 上、启动命令含 `start.mjs` 的 Node 进程及其子进程，不会按名称批量关掉所有 Node。

启动脚本不会自动安装任何东西。Node、ffmpeg、ffprobe 或页面缺失时，它会停下来告诉你原因。源码版如果有 Vite，会照常打包页面。

作品和任务存到项目里的 `数据/`，错误记录在 `日志/`。升级时先保留自己的 `.env.local` 和数据，别用新包覆盖它们。修改 ARK/TOS 配置保存后，下一次请求会重读；改了本地环境配置，建议关窗口再重新启动。

## 选装深度

需要 NVIDIA 显卡，以及支持 **CUDA 12.8 或更新版本**的驱动。安装器检查的是 `nvidia-smi` 表头的 CUDA Version，不要求单独装 CUDA Toolkit。没有 NVIDIA 显卡就跳过深度，其他功能不受影响。显存是否够还取决于视频尺寸和长度，安装通过不代表任何视频都能算。

建议预留 **约 15 GB 空闲硬盘**：安装过程中 `runtime/` 最多约 15 GB，自检通过后自动清掉下载缓存，剩约 8 GB（2026-11-01 在一台 RTX 5080 笔记本上实测；那次网速快，全程约 2 分钟，慢网要久得多）。作品空间另算。

1. 双击 `安装深度.bat`，等待七步完成。它会在项目 `runtime/` 里放便携 uv、Python 3.11、独立 Python 环境、固定版本 Video-Depth-Anything 源码和 Small 权重。不会装全局 Python、改系统 PATH 或注册表，也不会自动安装显卡驱动。
2. 国内网络下载慢时，在整合包文件夹打开终端，运行：

   ```powershell
   .\安装深度.bat --cn
   ```

   `--cn` 把普通 Python 包换到清华镜像、权重优先用 hf-mirror；torch 仍走官方 cu128 源。普通模式下 HF 下载失败也会自动换镜像。
3. 中断后可以重新双击。已完成的步骤会检查后跳过；下载尽量续传，不支持续传或校验不对会重下。源码目录若被手工改动或不完整，脚本会提示移走它后重试，不会覆盖现有源码目录。
4. 安装器只补 `.env.local` 里缺少或仍为提示文字的 `DEPTH_PYTHON`、`DEPTH_MODEL_DIR`，写成新环境的绝对路径；已有不同配置会保留，并显示如何改成新路径。它不会打印 ARK/TOS 密钥。如果你保留了旧路径，本次自检验证的是新装环境，实际使用仍以 `.env.local` 为准。
5. 看到 CUDA 和 VDA 导入自检通过后，重新双击 `一键启动.bat`。如果移动整个项目文件夹，需要更新这两个绝对路径，或再次运行安装器后按提示修改。

只想预览步骤、暂时不安装：

```powershell
.\安装深度.bat --dry-run
```

固定组合是 torch 2.8.0、torchvision 0.23.0（cu128），numpy 2.2.6、opencv-python-headless 4.12.0.88、easydict 1.13、einops 0.8.1、tqdm 4.67.1。不需要 xformers。请勿直接照 VDA 旧 requirements 安装 torch 2.1.1，它不支持 RTX 50 系。VDA 源码固定 commit 为 `4f5ae23172ba60fd7bc11ef671cca678842c7072`，遵循 Apache-2.0；模型和第三方组件以各自许可为准。

## 选装白模（手动准备，脚本只体检）

白模使用 Windows ComfyUI 便携版和四个模型。可从 [ComfyUI 仓库](https://github.com/Comfy-Org/ComfyUI) 的 Windows Portable 说明进入 NVIDIA 便携版下载，解压到项目的 `runtime/ComfyUI_windows_portable/`。不要拿桌面版的目录来代替便携版。

作者测试环境的版本是 **ComfyUI 0.43.0**，源码 commit `426f5eea52a7ece1dd599fff4cb6cd1f352ddd24`。下面所需节点在该版本**都是 ComfyUI 自带的，无需另外安装 custom_nodes 节点包**：

| 功能 | 需要的节点 | 在 ComfyUI 内的文件 |
| --- | --- | --- |
| 视频读写 | LoadVideo、GetVideoComponents、CreateVideo、SaveVideo | `comfy_extras/nodes_video.py` |
| 通用加载与编码 | CheckpointLoaderSimple、CLIPTextEncode、UNETLoader | `nodes.py` |
| 人物跟踪 | SAM3_VideoTrack | `comfy_extras/nodes_sam3.py` |
| 检测 | RTDETR_detect | `comfy_extras/nodes_rtdetr.py` |
| 几何 | LoadMoGeModel、MoGeInference、MoGeGeometryToFOV | `comfy_extras/nodes_moge.py` |
| 人体白模 | SAM3DBody_Loader、SAM3DBody_Predict、SAM3DBody_Smooth、SAM3DBody_Render | `comfy_extras/nodes_sam3d_body.py` |

旧便携版若缺内置节点，需要更新/更换便携版。只创建一个同名文件夹不能补上节点。本次未在干净电脑测试自动安装，所以不提供白模自动安装脚本。

把四个模型保持原文件名放在下面的相对位置（从便携版最外层开始）：

| 模型文件 | 放置位置 | 下载来源 | 大小（GB） |
| --- | --- | --- | --- |
| `sam3.1_multiplex_fp16.safetensors` | `ComfyUI/models/checkpoints/` | [Comfy-Org/sam3.1](https://huggingface.co/Comfy-Org/sam3.1/resolve/main/checkpoints/sam3.1_multiplex_fp16.safetensors) | 1.7 GB |
| `sam_3d_body_dinov3_bf16.safetensors` | `ComfyUI/models/detection/` | [Comfy-Org/sam-3d-body](https://huggingface.co/Comfy-Org/sam-3d-body/resolve/main/detection/sam_3d_body_dinov3_bf16.safetensors) | 2.8 GB |
| `rt_detr_v4-x-hgnet_fp32.safetensors` | `ComfyUI/models/diffusion_models/` | [Comfy-Org/RT-DETR](https://huggingface.co/Comfy-Org/RT-DETR/resolve/main/diffusion_models/rt_detr_v4-x-hgnet_fp32.safetensors) | 0.2 GB |
| `moge_2_vitl_normal_fp16.safetensors` | `ComfyUI/models/geometry_estimation/` | [Comfy-Org/MoGe](https://huggingface.co/Comfy-Org/MoGe/resolve/main/geometry_estimation/moge_2_vitl_normal_fp16.safetensors) | 0.7 GB |

4 个链接 2026-11-01 联网核过，大小与作者能跑通的环境一致。四个模型合计约 5.5 GB，还要加上便携版和缓存空间。国内下载慢时可把链接域名换成 `hf-mirror.com`。链接和字节数统一维护在 `scripts/mesh-requirements.mjs`，上表按该配置列出，GB 按十进制换算并保留一位小数。

在 `.env.local` 填 `COMFYUI_DIR`：指向包含 `python_embeded/` 和 `ComfyUI/` 两个文件夹的便携版最外层目录，填你自己电脑上的完整绝对路径。`COMFYUI_URL` 留空时用 `http://127.0.0.1:8188`，只接受本机地址。

双击 `检查白模环境.bat`，逐条看 ✓ / ✗，按后面的说明补缺项。也可以不改配置先检查指定目录：

```powershell
.\检查白模环境.bat --comfyui-dir "你解压的便携版完整路径"
```

体检只读文件，不启动 ComfyUI、不执行 Python、不下载东西。全部 ✓ 只表示文件齐全；节点加载、驱动兼容、模型是否正确以及推理效果仍需实际运行验证。GG TV 使用白模时可按配置自动启动便携版；已有自己打开的 ComfyUI 时会尝试复用。

## 常见问题

- **5290 被占用**：黑窗口会显示占用进程号。先确认是不是上一次的 GG TV；是的话双击 `停止.bat`。是别的程序就先查清楚，不要乱关。
- **提示代理假地址 / fake-IP / TUN**：当前网络模式可能不兼容。可关闭代理的假地址模式，或改用兼容的 Clash Verge，再重试。不要改密钥来解决网络问题。
- **找不到 ffmpeg 或 ffprobe**：运行上面的 winget 命令后，关闭旧窗口重新双击。安装器不会替你修改系统 PATH。
- **没有 NVIDIA 显卡**：跳过深度。安装器不会尝试 CPU 深度推理，也不会影响普通出图、视频等功能。
- **提示更新 NVIDIA 驱动 / CUDA 不可用**：先安装适合自己显卡的新版驱动，再重跑深度安装器。安装器不会代装驱动。
- **GitHub 连不上或下载慢**：开代理，或在当前终端设置 `HTTPS_PROXY` 后运行安装 bat。curl 也识别 `HTTP_PROXY`。下面仅为本机代理地址格式示例，端口要换成你自己的；终端里的设置只对从该终端启动的命令生效。

  ```powershell
  $env:HTTPS_PROXY = 'http://127.0.0.1:你的代理端口'
  .\安装深度.bat --cn
  ```

- **启动窗口提示找不到页面**：确认完整解压的是整合包，里面应有 `dist/index.html`。不要只下载仓库源码冒充整合包。
- **白模体检通过但运行失败**：先看 ComfyUI 的原始错误和 GG TV 的 `日志/`，文件齐全不等于能加载。不要随意改工作流、换同名模型或关掉检查。
